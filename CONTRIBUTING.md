# Contributing to AI Tool Kit

Thanks for taking the time to contribute! 🎉

## How to Add a Tool

1. **Fork** this repository
2. **Clone** your fork locally
3. Add your tool to the relevant section in `README.md`
4. Follow the format below
5. Open a **Pull Request** with a short description of what you added

## Tool Entry Format

Each tool should follow this table format:

```
| **Tool Name** | Short description of what it does | Best use case | [link](https://url.com) |
```

## Guidelines

- Only add tools that are **publicly available**
- Include a **direct link** to the tool
- Keep descriptions **short and neutral** — no marketing language
- Place the tool in the **most relevant category**
- If a tool fits multiple categories, pick the primary one
- Check that the tool isn't **already listed** before adding

## Suggesting a New Category

If your tool doesn't fit any existing category, open an **Issue** first to discuss adding a new one before submitting a PR.

## Reporting Broken Links

If you find a broken link or outdated tool, open an Issue or submit a PR with the fix.
